01THE WORK

Make the boundaries visible.

An AI agent can request an action. That doesn't mean the action should be trusted. The toolkit explores ways to test the boundary between a request, an authorized operation, and a result that can be checked.

01 ↗

Access & permissions

Challenge file-access boundaries, unexpected paths, and operations that should be denied.

02 ↗

Failure & recovery

Exercise interruptions, uncertain outcomes, and situations where retrying could be unsafe.

03 ↗

Evidence & verification

Check whether recorded events support the claimed result—and where audit assumptions break down.

02OUR APPROACH

NO SHORTCUT TO TRUST

A passing test is a starting point.
Not a promise.

We document what a test actually covers, where the evidence stops, and what still needs independent review. A prototype is not a sandbox, and research results are not a guarantee of protection.

PUBLIC PRE-RELEASE · NOVEMBER 6, 2026

ZAXWEIR Toolkit v0.5.0rc8 is available.

RESEARCH / TESTING PRE-RELEASE

The standalone ZAXWEIR Agent Security Toolkit is now published under Apache-2.0. It is a free, offline Python testing harness for agent permission boundaries, human approvals, audit records, and Windows filesystem safety. This is a pre-release, not a production sandbox or security certification.
